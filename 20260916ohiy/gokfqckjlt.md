# 【科普】产后出血该怎么办？

> 更新时间：2026-09-16 (UTC+8)

**产后出血健康教育处方**
#
产妇加强营养，给予高热量、高蛋白、高维生素饮食，多食富含铁的食物，如瘦肉、动物内脏等，并少量多餐，进食易消化饮食。

#
产妇应坚持哺乳，母乳喂养，有助于减少产后出血和子宫复旧。

#
产后保留计血垫以便准确记录出血量，注意清洁卫生，勤换内衣裤及卫生巾，大小便后应清洗会阴部。 

#
保证睡眠8-9h/d，保持心情舒畅，减少紧张。 

#
在血色素基本恢复正常后，应下床活动，第一次下床时应有家属在旁协助，遵循三个30秒的下床三部曲，活动应循序渐进，防止跌倒，逐渐增加活动量，恢复自理。

#
了解产后复查的时间、目的和意义并接受产后健康指导。

#
医护会为您讲解贫血药物使用注意事项，如蔗糖铁、多糖铁、维生素B族、叶酸等，协助您正确服用。
